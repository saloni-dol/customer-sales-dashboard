# Explainable AI for Healthcare Diagnosis

## 📌 Project Overview
This project builds a machine learning model to predict breast cancer diagnosis and explains predictions using explainable AI techniques such as SHAP and LIME.

## 🎯 Objectives
- Train accurate ML models for medical diagnosis
- Improve transparency using explainable AI
- Provide interpretable insights for healthcare decision-making

## 🧠 Models Used
- Logistic Regression
- Random Forest
- XGBoost

## 📊 Explainability
- SHAP summary plots
- Feature importance analysis

Python, Pandas, Scikit-learn, SHAP, Matplotlib, Power BI
